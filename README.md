# tic-tac-toe
a tic tac toe game with pre done unit tests and source code.


This is a tic tac toe game that runs among 2 real players. However it has one issue or i should call it feature, you can actually choose you symbol to be something other than the good old "X" and "O" (yes, this is intentional.), although it still cant be same symbol for both players, i should call this a feature too.

anyways, it come with 2 unite tests in test.py where it tests the code for error. Right now it only has test for 2 functions and cant test those that nee human input.
